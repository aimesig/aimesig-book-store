Back up your library

Books added here are saved in this browser using local storage technology (IndexedDB). They are not automatically uploaded to GitHub or shown to other visitors.

To publish a book for everyone: add its cover and chapter HTML files to the GitHub repository, then add its details to assets/catalog.js. See the README for the exact steps. GitHub Pages is static hosting, so this form cannot write files back to your repository.

Export creates a JSON backup containing your locally added book details, cover images, and chapter HTML. Import it on another browser to restore your local library there.
