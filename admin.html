Books you add here are saved in this browser, and will appear in its library immediately. They stay available on this device after refreshing the page.

About publishing on GitHub Pages
GitHub Pages is static hosting. This form cannot write new files to your GitHub repository, so books added here are private to this browser. To make a book visible to every visitor, add its cover and chapter HTML files to the repository and register it in assets/catalog.js. The README includes a ready-to-copy example.
