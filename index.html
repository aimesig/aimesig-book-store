Back up your library

Books added here are saved in this browser using IndexedDB. They are not automatically uploaded to GitHub or shown to other visitors.

To publish a book for everyone: add its cover and chapter HTML files to the GitHub repository, then add its details to assets/catalog.js. See the README for the exact steps. GitHub Pages is static hosting, so this form cannot write files back to the repository.

Export creates a JSON backup of your locally added books, covers, and chapters. Import it on another browser to restore your library.
